# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - Unreleased

### Added

- Databricks SparkSQL parser wrapper using `sqlglot`.
- Logical query model for a conservative single-table analytical subset.
- DAX emitter for projection, filtering, grouping, aggregation, ordering, and limits.
- CLI entry point.
- Optional TOML metadata mapping for semantic model names.
- Tests, CI, MIT license, contribution guide, and security policy.
